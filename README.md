# Floricultura

Prova P3 de CMP2304 (Tecnologia de Construção de Software I), Versão 07.

App Flutter que gerencia registros de flores em memória (Flor, Cor e Fornecedor):
listagem, cadastro, edição, exclusão e validação de campos vazios. Usa
StatefulWidget, setState e navegação entre telas.

## Como rodar

```
flutter create .
flutter run
```

O `flutter create .` gera as pastas de plataforma (android, web etc.) sem mexer em
`lib/` nem no `pubspec.yaml`.
